# PhysioFlow

Sistema web para gestão de fisioterapeutas autônomos e pequenas clínicas.

O objetivo do projeto é simplificar o gerenciamento de pacientes, atendimentos e informações clínicas, oferecendo uma interface moderna, intuitiva e focada na rotina do profissional.

## Funcionalidades

- Cadastro de pacientes
- Agenda de atendimentos
- Histórico clínico
- Dashboard com indicadores
- Controle de sessões
- Gestão de informações do paciente

> **Status:** Em desenvolvimento (MVP)

---

## Tecnologias

- React
- TypeScript
- TanStack Start
- Tailwind CSS
